# Zournel 📓✨

> **Zournel** is a seamless, AI-powered personal journaling and task management application designed for focus, reflection, and getting things done.

![Zournel Banner](https://via.placeholder.com/1200x400/1E1B4B/818CF8?text=Zournel+_+Journal+Meets+Task+Manager)

## 🌟 Feature Highlights

* **🧠 AI-Powered Task Breakdown:** Generate step-by-step subtasks for any complex item on your list instantly.
* **✍️ Smart Journaling:** Write freely and let AI automatically extract tasks, detect your mood, and suggest titles.
* **📱 Mobile First & Touch Friendly:** Generous touch targets and fluid layouts ensure perfect usability on any device.
* **☁️ Cloud Backup:** Securely sync your journal entries and tasks with Firebase Firestore.
* **🎨 Customizable Themes:** From 'Cozy Dark' to 'Catppuccin'—make it yours.

## 🚀 Local Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/devRIKU/Zournel.git
   cd Zournel
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Copy `.env.example` to `.env.local` and add your Firebase and Gemini API credentials:
   ```bash
   cp .env.example .env.local
   ```
   *Note: Do not commit `.env.local` to version control.*

4. **Run the Development Server:**
   ```bash
   npm run dev
   ```
